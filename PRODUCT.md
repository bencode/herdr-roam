# Product

## Register

product

## Users

Herdr Roam serves experienced individual software developers who coordinate multiple local AI coding agents. They need to inspect ongoing work, provide direction, review durable artifacts, and move between projects without rebuilding context in every conversation.

## Product Purpose

Herdr Roam is a personal AI software studio built above one local Herdr server. It provides a durable coordination workspace for Projects, Agents, Sessions, Issues, Loops, files, and Skills while preserving native agent and Git workflows. Success means a developer can understand current work, intervene deliberately, and reuse accumulated capabilities without treating every agent session as an isolated chat.

## Brand Personality

Restrained, precise, and technical. The interface should feel trustworthy and focused under sustained daily use, with the density and predictability of a mature development tool.

## Anti-references

- A clone of Herdr's workspace UI or a browser terminal presented as the whole product.
- A card-heavy SaaS dashboard that obscures working context behind summaries and decoration.
- A chat application that invents conversational structure when the underlying runtime only exposes terminal output.
- Novel controls, excessive motion, or visual effects that compete with code, documents, and Agent activity.

## Design Principles

- Keep the work artifact primary; chrome and metadata remain secondary.
- Keep Session and artifact reading separate from runtime control: opening an Agent connects its native Terminal; taking over another controller remains explicit.
- Represent runtime truth honestly instead of inferring unsupported turns, ownership, or completion.
- Preserve context across resources so users can compare and coordinate without restarting their mental model.
- Prefer familiar IDE interactions and compact, consistent component behavior over novelty.

## Accessibility & Inclusion

Use WCAG AA as the baseline for text contrast, focus visibility, keyboard operation, and state communication. Do not rely on color alone, respect reduced-motion preferences, and keep Session reading and native Agent interaction operable without a pointer.
