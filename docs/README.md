# Herdr Roam Documentation

Herdr Roam is in its early design stage. These documents record the product
decisions and technical boundaries that guide its first implementation.

## Documents

- [Vision and scope](product/vision-and-scope.md) explains the problem Herdr
  Roam solves, its product principles, its initial capabilities, and its
  explicit non-goals.
- [System overview](architecture/system-overview.md) describes the local Web
  architecture, runtime boundaries, technology choices, and security model.
- [Workbench interactions](design/workbench-interactions.md) records the
  desktop information architecture, ASCII wireframes, and primary interaction
  flows.

The product documents describe intent. The architecture documents describe how
the current design supports that intent. Neither should be treated as a promise
of unimplemented functionality.
